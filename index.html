IMN Core

Herramienta privada de INFINITE MEDIA NETWORK para administrar sus propios canales de vídeo y redes sociales desde un ordenador local. No es un servicio público ni se ofrece a terceros.

Qué es IMN Core

IMN Core es una aplicación de escritorio que se ejecuta en el equipo del propietario de los canales. Programa publicaciones, comprueba que se hayan publicado correctamente y descarga estadísticas de los canales que el propio operador ha autorizado. Utiliza las interfaces oficiales de cada plataforma, como la YouTube Data API y la YouTube Analytics API de Google.

Política de privacidad

Última actualización: 9 de noviembre de 2026.

Esta política describe qué datos trata IMN Core cuando un usuario autoriza el acceso a su cuenta de Google o de otra plataforma.

  • Qué datos se usan. Metadatos de los canales y vídeos del usuario autorizado (título, descripción, estado de publicación, estadísticas de visualizaciones, suscriptores y rendimiento) y los archivos de vídeo que el propio usuario decide publicar.
  • Para qué. Exclusivamente para publicar contenidos en los canales del usuario, verificar esas publicaciones y mostrar sus estadísticas al propio usuario. No se usan para publicidad, perfilado ni ningún otro fin.
  • Dónde se guardan. En el ordenador del usuario, en una base de datos local. Los tokens de acceso se guardan cifrados en el almacén de credenciales del sistema operativo. Nada se envía a servidores de INFINITE MEDIA NETWORK ni de terceros, salvo a las propias plataformas (por ejemplo, Google) a través de sus API oficiales.
  • Con quién se comparten. Con nadie. Los datos no se venden, ceden, transfieren ni divulgan a terceros.
  • Datos de Google. El uso y la transferencia de información recibida de las API de Google por parte de IMN Core se ajustan a la Política de Datos del Usuario de los Servicios de las API de Google, incluidos los requisitos de uso limitado.
  • Conservación y eliminación. Los datos se conservan mientras el usuario mantenga la autorización. El usuario puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions o con el comando de revocación de la aplicación, que borra los tokens almacenados.
  • Menores. IMN Core no está dirigido a menores de edad y no recopila datos de menores a sabiendas.

Condiciones de uso

IMN Core es software de uso interno de INFINITE MEDIA NETWORK. Se proporciona tal cual, sin garantías, para uso exclusivo del propietario de los canales que autoriza. Cada usuario es responsable del contenido que publica y del cumplimiento de las condiciones de las plataformas en las que publica.
